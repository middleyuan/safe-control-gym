# Plotting Guide for Safe Control Gym Benchmarking

This guide provides command-line instructions for generating various types of plots for the Safe Control Gym quadrotor benchmarking analysis.

## Data Setup

Run plotting and processing commands from `benchmarking_sim/quadrotor/plotting`.
The shell wrappers also switch to this directory automatically.

Use `data/` in this folder as the plotting workspace. Before processing, place
the curated experiment folders you want to plot under a dataset subfolder, for
example:

```text
data/<dataset_name>/
├── generalization/
├── nominal/
├── obs_noise/
├── param/
├── proc_noise/
└── robustness_combo/
```

Only include folders that are relevant to the plots you want to generate. For
example, robustness plots need `obs_noise/`, `proc_noise/`, `param/`, and
optionally `robustness_combo/`; convergence plots use RL training folders under
`nominal/`; model-based generalization plots use `generalization/`.

For regular RL methods in `generalization_curve_all`, the processor reads
transfer metrics from `nominal/` so the curve reflects nominally trained
policies evaluated across task lengths. RL variants are separated by source:
`generalization/` becomes `GEN`, while `robustness_combo/` becomes `DR`.

Process the staged dataset into the flat files used by plotting scripts:

```bash
# Reads from data/<dataset_name>/ and writes processed files to data/
python process_experiment_data.py all --input-data-root=<dataset_name>

# or
SCG_PLOTTING_INPUT_ROOT=<dataset_name> python process_experiment_data.py all
```

If `data/Final_june/` exists, `process_experiment_data.py` uses that as the
default input dataset. Otherwise it reads directly from `data/`. Processed
outputs are always written to `data/`, where the plotting scripts read them.

Useful processing commands:

```bash
# Process everything
python process_experiment_data.py all --input-data-root=<dataset_name>

# Process robustness data
python process_experiment_data.py robustness obs_noise all
python process_experiment_data.py robustness proc_noise all
python process_experiment_data.py robustness param all

# Process trajectory/path data
python process_experiment_data.py trajectory all

# Process generalization data
python process_experiment_data.py generalization all

# Process domain randomization data
python process_experiment_data.py domain-randomization
```

Model-based rollouts generated by `../mb_rollout.sh` are upstream source
material. Move the selected output folders into your plotting dataset folder
first; the plotting processor should operate on the staged copy.

## 1. Generalization Plots

### Control + RL Methods
```bash
python plot_generalization.py all
```

### RL Methods Only
```bash
python plot_generalization.py rl
```

### Control Methods Only
```bash
python plot_generalization.py control
```

### RL Methods with Domain Randomization
```bash
# Add DR variants from robustness_combo next to nominal RL methods
python plot_generalization.py rl --include-dr

# Replace nominal PPO/SAC/DPPO with DR variants from robustness_combo
python plot_generalization.py rl --use-dr
python plot_generalization.py all --use-dr

# Add GEN variants from generalization next to nominal RL methods
python plot_generalization.py rl --include-gen

# Replace nominal PPO/SAC/DPPO with GEN variants from generalization
python plot_generalization.py rl --use-gen
python plot_generalization.py all --use-gen

# Combine modes: use GEN as replacement and add DR for comparison
python plot_generalization.py all --use-gen --include-dr
```

Generalization outputs include the selected variant mode in the filename, for
example `generalization_curve_all_use_gen.png`,
`generalization_curve_all_use_dr.png`, or
`generalization_curve_all_use_gen_with_dr.png`.

## 2. Robustness Plots

### Control Methods
```bash
# Observation noise
python plot_noise_robustness.py obs_noise control

# Process noise
python plot_noise_robustness.py proc_noise control

# Parametric uncertainty
python plot_noise_robustness.py param control
```

### RL Methods
```bash
# Observation noise
python plot_noise_robustness.py obs_noise rl

# Process noise
python plot_noise_robustness.py proc_noise rl

# Parametric uncertainty
python plot_noise_robustness.py param rl
```

### RL Methods with Domain Randomization
```bash
# Combined RL vs RL+DR tables/plots for all three robustness cases
python plot_noise_robustness.py all rl --include-dr

# Include both regular and DR variants
python plot_noise_robustness.py obs_noise rl --include-dr
python plot_noise_robustness.py proc_noise rl --include-dr
python plot_noise_robustness.py param rl --include-dr

# Plot ONLY domain randomization variants
python plot_noise_robustness.py obs_noise rl --dr-only
python plot_noise_robustness.py proc_noise rl --dr-only
python plot_noise_robustness.py param rl --dr-only
```

### All Methods Combined
```bash
# All noise types
python plot_noise_robustness.py all

# All methods for each noise type
python plot_noise_robustness.py obs_noise all
python plot_noise_robustness.py proc_noise all
python plot_noise_robustness.py param all

# All methods including domain randomization
python plot_noise_robustness.py obs_noise all --include-dr
python plot_noise_robustness.py proc_noise all --include-dr
python plot_noise_robustness.py param all --include-dr
```

Robustness outputs include relative and absolute threshold tables. For a single
noise case, the tables summarize the first tested noise scale above 200%
relative RMSE and 0.25m absolute RMSE. With `all`, combined tables are also
saved across observation noise, process noise, and parametric uncertainty, for
example `robustness_all_methods_all_relative_table.png` and
`robustness_all_methods_all_absolute_table.png`.

For the RL vs RL+DR comparison table, use:

```bash
python plot_noise_robustness.py all rl --include-dr
```

This saves `robustness_rl_methods_all_relative_table_with_dr.png` and
`robustness_rl_methods_all_absolute_table_with_dr.png`.

## 3. Custom Ridge Plots

### Basic Ridge Plots
```bash
# Compare specific controllers for observation noise
python plot_custom_ridge_levels.py obs_noise lqr fmpc mpc_acados sac

# Compare RL methods for process noise
python plot_custom_ridge_levels.py proc_noise ppo sac dppo

# Compare control methods for parametric uncertainty
python plot_custom_ridge_levels.py param lqr ilqr linear_mpc_acados
```

### Ridge Plots with Domain Randomization
```bash
# Include domain randomization for specific RL controllers
python plot_custom_ridge_levels.py obs_noise lqr fmpc mpc_acados sac --include-dr sac
python plot_custom_ridge_levels.py proc_noise ppo sac dppo --include-dr ppo sac dppo
python plot_custom_ridge_levels.py param sac dppo --include-dr sac dppo
```

### Comprehensive Comparisons
```bash
# All main controller types with DR for SAC
python plot_custom_ridge_levels.py obs_noise lqr linear_mpc_acados mpc_acados gpmpc_acados_TP sac --include-dr sac

# RL methods comparison with domain randomization
python plot_custom_ridge_levels.py obs_noise ppo sac dppo ppo_mpc --include-dr ppo sac dppo
```

## 5. Spider/Radar Plots

Radar plots summarize one controller across performance, generalization,
computation, model knowledge, sampling complexity, and robustness metrics.

```bash
# Relative robustness version
python plot_radar.py ppo

# Absolute robustness version
python plot_radar.py ppo abs
```

The first argument is the controller tag. Examples:

```bash
python plot_radar.py sac
python plot_radar.py dppo
python plot_radar.py ppo_mpc
python plot_radar.py mpc_acados
python plot_radar.py lqr
```

The relative version saves to `radar/`, while the absolute version saves to
`radar_abs/`. The radar script uses processed generalization metrics and
`data/robustness_failure_points.json`, so run the data processor first:

```bash
python process_experiment_data.py all --input-data-root=<dataset_name>
```

## 6. Convergence

```bash
# RL training convergence analysis
python plot_convergence.py all                    # All RL methods
python plot_convergence.py ppo                    # PPO only
python plot_convergence.py sac                    # SAC only
python plot_convergence.py dppo                   # DPPO only
python plot_convergence.py ppo_mpc                # PPO-MPC only
python plot_convergence.py all --include-dr       # Include domain randomization
```

Convergence plots read raw RL training logs from the curated input dataset,
not from the processed flat `.npy` files. By default this is
`data/Final_june/nominal/` when `data/Final_june/` exists, otherwise
`data/nominal/`. You can choose a dataset explicitly:

```bash
python plot_convergence.py all --input-data-root=<dataset_name>
SCG_PLOTTING_INPUT_ROOT=<dataset_name> python plot_convergence.py all
```

## Available Controllers

### Model-based Controllers
- `linear_mpc_acados` - Linear MPC
- `mpc_acados` - Nonlinear MPC
- `gpmpc_acados_TP` - GP-MPC
- `ilqr` - iLQR
- `lqr` - LQR
- `pid` - Geometric Control
- `fmpc` - F-MPC

### RL Controllers
- `ppo` - Proximal Policy Optimization
- `sac` - Soft Actor-Critic
- `dppo` - Distributed PPO
- `ppo_mpc` - PPO with MPC

### Noise Types
- `obs_noise` - Observation noise
- `proc_noise` - Process noise
- `param` - Parametric uncertainty

## Output Locations

Generated plotting data is saved in:

- **Processed plot outputs**: `data/`

All plots are saved in the following directories:

- **Robustness plots**: `noise/`
- **Generalization plots**: `generalization/`
- **Trajectory plots**: `trajectory/`
- **Custom ridge plots**: `custom_plots/`
- **Radar plots**: `radar/`
- **Absolute radar plots**: `radar_abs/`
- **Convergence plots**: `convergence/`

Each plot is saved in both PNG and PDF formats for publication use.

---

## Common Flags

- `--include-dr`: Include domain randomization variants along with regular methods
- `--use-dr`: Replace regular PPO/SAC/DPPO curves with robustness-combo DR variants where available
- `--include-gen`: Include generalization-trained variants along with regular methods
- `--use-gen`: Replace regular PPO/SAC/DPPO curves with generalization-trained variants where available
- `--dr-only`: Plot only domain randomization variants (RL methods only)
- `control`: Filter to model-based controllers only
- `rl`: Filter to reinforcement learning methods only
- `all`: Include both control and RL methods

## Troubleshooting

1. **No data files found**: Run the data processing script first:
   ```bash
   python process_experiment_data.py all
   ```
2. **Missing specific data type**: Process the required analysis:
   ```bash
   python process_experiment_data.py robustness obs_noise all
   python process_experiment_data.py trajectory all
   python process_experiment_data.py generalization all
   python process_experiment_data.py domain-randomization
   ```
3. **Missing controllers**: Check that all required processed plotting files exist in `data/`
4. **Plot formatting issues**: Ensure matplotlib and seaborn are up to date

For additional help, check the individual script documentation with `python <script_name>.py --help`.

## Data Processing Reference

The `process_experiment_data.py` script supports the following analysis types:

### Comprehensive Processing
```bash
# Process all data types for all controllers (recommended)
python process_experiment_data.py all

# Process all data types for specific method category
python process_experiment_data.py all control  # Model-based only
python process_experiment_data.py all rl       # RL methods only
```

### Specific Analysis Types
```bash
# Robustness analysis (requires noise type)
python process_experiment_data.py robustness obs_noise all
python process_experiment_data.py robustness proc_noise control
python process_experiment_data.py robustness param rl

# Trajectory analysis
python process_experiment_data.py trajectory all
python process_experiment_data.py trajectory control

# Generalization analysis  
python process_experiment_data.py generalization all
python process_experiment_data.py generalization rl

# Domain randomization (RL methods only)
python process_experiment_data.py domain-randomization
```

### Controller-Specific Processing
```bash
# Process specific controller for all analysis types
python process_experiment_data.py all --controller=linear_mpc_acados
python process_experiment_data.py all --controller=ppo

# Process specific controller for specific analysis
python process_experiment_data.py trajectory --controller=sac
python process_experiment_data.py robustness obs_noise --controller=gpmpc_acados_TP
```
